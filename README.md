Project Title: Modern Resume using HTML & CSS

Description:
I created a modern resume layout using HTML and CSS. This project is divided into two main sections: the left side and the right side.

The left side contains the profile picture and personal information.
The right side includes the name, objective, experience, and references.

What I Learned:

Basic HTML tags and structure
CSS styling and layout design
How to divide a page into left and right sections
Using Flexbox to align and position content properly
Creating lines and sections for better design (top, bottom, and side borders)

Purpose of the Project:
The main goal of this project was to practice front-end development skills and understand how to create a clean and professional layout.
**Title:** Complete School Website Using HTML and CSS

**Description:**
I have created a complete school website project using HTML and CSS. This project includes multiple sections and features to represent a modern school website.

First, I designed a navigation bar that includes links such as Home, About, and Admission. Then, I created a hero section for the main introduction of the website.

After that, I developed an About section that includes feature cards. Inside this section, I also added a Principal’s message with an image, a Departments section with cards, a Facilities section, and a Teachers section that displays teacher names and pictures.

Next, I built a Statistics section to show the school’s records and achievements. I also added a Gallery section to showcase pictures of the school.

Finally, I created a footer that includes contact information and social media links. The Admission section includes an admission form and contact details for inquiries.

This project helped me improve my layout design, structuring, and CSS styling skills.
